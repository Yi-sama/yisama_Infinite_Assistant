## 上线必须改的地方（`app.js`）

1. `PRICING_URL = 'api/pricing'` → `'/api/pricing'`（公开接口，无需登录，已核对字段：`data[].model_name / quota_type / model_ratio / completion_ratio / model_price / enable_groups / billing_expr`，`group_ratio`，`usable_group`）。
2. `index.html` 里三张站内应用卡片的 `--img:url(site/media/...)` 改成绝对路径 `/site/media/...`。
3. `api` 对象（目前是假数据）：

| 函数 | 真实实现 | 备注 |
|---|---|---|
| `createKey()` | `POST /api/token/`，name 固定如 `简洁模式`，`group = state.group`，不限额、不过期；然后读出完整 key | 先 `GET /api/token/` 找同名 Key，有就复用，不要重复建 |
| `setGroup(g)` | `PUT /api/token/` 改该 Key 的 `group` | 换厂商/线路时调用，Key 不变 |
| `balance()` | `GET /api/user/self` → `data.quota / 500000`（`quota_per_unit=500000`，1:1 显示为 ¥） | |
| `week()` | `GET /api/log/self?token_name=简洁模式&start_timestamp=...` → `{ calls: [7 天次数], spent: 历史扣费合计 }` | 消费日志（`type=2`）按天计数，`quota` 合计 / 500000 得到 `spent`；取全分页。缺少金额时返回 `null` 显示“花费待同步”，不能按当前模型价格重算历史 |
| 首次调用检测 | 每 3 秒查一次该 Key 的日志，有任意一条 `type=2` 就调用 `gotFirstRequest()` | 原型里由“模拟第一次调用”按钮触发 |

   new-api 的用户接口需要会话 Cookie + `New-Api-User: <user_id>` 请求头，同源调用即可。未登录（401）时跳 `/sign-in?redirect=/start/`。
   登录态检查可参考线上 `/site/auth.js`（`POST /api/user/auth/refresh`）。
4. `localStorage` 里存了 `ys.start.key`（完整 Key）。接真实接口后**不要再存 Key**，每次从 `/api/token/` 取。
5. 充值 `.js-pay`：改为调用 new-api 现有支付宝下单接口（`PayAddress = https://pay.yisama.asia`，`MinTopUp = 1`），回跳 `/start/?paid=1` 后轮询余额，到账再播放成功动画。兑换码 `.js-redeem` → `POST /api/user/topup`。
6. 首次选择弹窗：选“专业模式”应跳转 `/console`（现在只是 toast）。
7. 无限助手卡片 `[data-assist]`：换成 `Yisama-Setup.exe` 的真实下载地址（现在只是 toast）。安装包尚未签名，正式推广前需要签名。

## 可调的配置（`app.js` 顶部）

- `VENDORS`：厂商、匹配模型名的正则、默认模型/线路。GPT 默认 `不降智plus` + `gpt-6-luna`；国产默认 `deepseek-v4.1-flash`；Claude 默认 `claude-sonnet-5`、线路取倍率最高的可用分组（目前是“满血ccm 正价”）。
- `HOT`：默认展开显示的热门模型，其余折叠。
- `SCENES`：估算场景的 token 数（hi 20/20；日常问答 600/800；改代码 40k 输入其中 32k 缓存 + 1.5k 输出）。
- 估算公式在 `baseCost()`：有 `billing_expr` 的用第一档系数；其他按 `model_ratio × 2 美元/百万 token`，输出再乘 `completion_ratio`，缓存按输入价的 0.1 算，最后乘分组倍率。
