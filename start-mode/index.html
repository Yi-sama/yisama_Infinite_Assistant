    先确认 Codex 已装好

    不确定？如果你是双击图标打开的，就是桌面版。

    1. 按 Win 键，输入 PowerShell，回车打开，运行：
      codex --version
    2. 如果提示“无法识别 codex”，先按 官方 Windows CLI 安装说明完成安装，再重新打开 PowerShell，运行同一条命令。
    3. 看到 codex-cli 和版本号后再继续。本站不会自动检测你电脑上的安装状态。
    1. 还没安装？从 Codex 官方 Windows 页面下载桌面版并完成安装。
    2. 从开始菜单打开 Codex，确认软件窗口能正常启动。已经能打开就不用重复安装。
    3. 安装或启动报错时，先按官方页面排查，再回来配置本站接入。本站不会自动检测你电脑上的安装状态。
